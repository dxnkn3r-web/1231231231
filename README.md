# Garden Shop — запуск в Open Server Panel

Проект подготовлен для Apache 2.4 (модуль apache_2.4-php_7.2-7.4), PHP 7.4 и MySQL 5.7. Требуются расширения PHP `pdo_mysql` и `json`. PHP 7.4 и MySQL 5.7 устарели: используйте эту конфигурацию только локально, не публикуйте её в интернете.

## Установка

1. Скопируйте **всю** папку `garden-shop.local` в папку доменов Open Server (например, `C:\OpenServer\domains\garden-shop.local`). Сохраните структуру папок, в том числе `public\uploads`.
2. В настройках Open Server выберите Apache `apache_2.4-php_7.2-7.4`, PHP `PHP-7.4` и MySQL `MySQL-5.7`. Настройте домен `garden-shop.local` так, чтобы его корневой каталог (DocumentRoot) указывал **на `garden-shop.local\public`**, а не на папку проекта. При необходимости добавьте домен вручную в настройках доменов Open Server. Включите обработку `.htaccess` (AllowOverride All). Перезапустите сервер.
3. В phpMyAdmin создайте пустую базу `garden_shop` с кодировкой `utf8mb4` и импортируйте в неё `public\sql\database.sql`. Файл содержит демонстрационные товары, но не содержит существующие заказы и пользователей.
4. По умолчанию подключение настроено на `127.0.0.1:3307`, пользователь `root`, пустой пароль. Если в Open Server используется другой порт или пароль, скопируйте `public\config\db.local.example.php` в `public\config\db.local.php` и измените значения. Порт смотрите в настройках модуля MySQL. Не добавляйте файл с паролем в Git.
5. Откройте `http://garden-shop.local/`. Зарегистрируйте пользователя. Для доступа к админке выполните в phpMyAdmin запрос, подставив email зарегистрированного пользователя:

   ```sql
   UPDATE users SET is_admin = 1 WHERE email = 'ваш-email@example.com';
   ```

   Затем откройте `http://garden-shop.local/admin.php`. Убедитесь, что папка `public\uploads` доступна на запись пользователю, от которого запущен Apache.

## Перенос существующих данных

Если у вас уже есть рабочая база магазина, сначала создайте её резервную копию и экспортируйте её через phpMyAdmin. Импортируйте этот дамп в созданную базу `garden_shop` вместо демонстрационного `database.sql`; также скопируйте фактическое содержимое папки `uploads` со старого сервера. При отсутствии таблицы `related_products` выполните в этой базе `public\sql\add_related_products.sql`. Демонстрационный SQL не является резервной копией существующей базы и не должен импортироваться поверх неё.

Проверьте каталог, карточку товара, регистрацию, корзину, оформление заказа, загрузку фото и админку. Синхронизация `api/sync_1c.php` — демонстрационная: она изменяет цены и остатки случайными значениями, а не подключается к реальной 1С.
