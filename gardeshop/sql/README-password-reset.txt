ВОССТАНОВЛЕНИЕ ПАРОЛЯ — УСТАНОВКА В OPEN SERVER

1. Сделайте резервную копию сайта и базы. Скопируйте файлы из архива в корневую папку сайта (ту, где находятся login.php и product.php). Перед заменой login.php сохраните его копию.
2. В phpMyAdmin выберите существующую базу сайта (например, gardenshop) и выполните SQL из sql/add_password_resets.sql. Не импортируйте database.sql поверх существующей базы.
3. Скопируйте config/mail.example.php в config/mail.local.php. Укажите site_url — точный адрес сайта, например http://gardeshop, и from — разрешённый вашим почтовым сервисом адрес отправителя.
4. Настройте отправку писем функцией PHP mail() в Open Server/PHP через работающий почтовый сервер. Для доставки нужны корректные настройки SMTP/почтового транспорта; настройки mail.local.php сами по себе отправку не включают. На Windows может потребоваться поддерживающий SMTP-прокси или sendmail-совместимая программа с аутентификацией. Подробности зависят от вашего почтового сервиса. На локальной машине письмо может не отправляться без этой настройки.
5. Откройте страницу входа, нажмите «Забыли пароль?» и проверьте доставку письма, переход по ссылке и вход с новым паролем. Локальный адрес http://gardeshop будет открываться только на компьютере, где настроен этот домен. Для доступного извне сайта используйте его реальный HTTPS-адрес и корректную конфигурацию сервера.

Ссылка одноразовая, действует один час. Сообщение на странице одинаково для существующих и отсутствующих аккаунтов. Интервал между запросами в одной сессии — минута. Для публичного сайта необходимы HTTPS, почтовая доставка, общесерверное ограничение частоты запросов и полноценный аудит безопасности; одного ограничения в сессии недостаточно.
